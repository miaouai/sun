# 🌞 向日窥 - Sun Peek

**阳台光照智能分析应用 · v1.4.1**

> 通过手机朝向检测 + 地理位置信息，AI 辅助决策，科学分析阳台日照情况的专业工具。

| 模块 | 功能说明 |

## 📋 使用流程

```
1. 打开 App → 授予定位和方向传感器权限 ✅

2. 设置阳台朝向
   ├─ 自动模式：水平放置手机，实时检测朝向
   └─ 手动模式：精确输入角度（如 90°=正东）

3. 配置阳台参数
   ├─ 阳台类型：凸出式 / 内嵌式 / L 型
   ├─ 封闭情况：开放式 / 单层玻璃 / 双层中空
   └─ 周边遮挡：左侧/右侧建筑物 + 顶部雨蓬角度

4. 设置位置信息
   ├─ 自动定位：GPS 获取当前经纬度
   └─ 手动输入：坐标 (纬度，经度)

5. 点击"🌅 开始分析"
   → 等待遮罩消失 → 查看完整报告 ⏱️ 约 1-2 秒

6. AI 智能助手（可选）
   ├─ 复制提示词 → 打开 AI 平台
   └─ 获得个性化生活建议
```

## 🔬 技术架构

### 前端技术栈
- **单文件架构** - `app.js` 75KB 整合全部逻辑
- **数据驱动 UI** - `config.json` 动态加载文本配置
- **模块化设计** - `data/*.js` 独立功能拆分包

```
sun/
├── index.html           # 页面结构（525 行）
├── app.js               # 主逻辑（907 行）
├── styles.css           # 主样式（26KB）
├── config.json          # UI 文本配置
├── CHANGES_v1.3.1.md    # 版本日志
└── data/                # 核心模块
    ├── ai-assistant.js      # AI 提示词生成
    ├── sun-calculations.js  # 日照计算引擎
    ├── noaa-sunrise.js      # NOAA 天文算法
    ├── solar_worker.js      # Web Worker 多线程
    ├── china-cities.json    # 中国城市数据库
    └── cities-cascade.js    # 联级菜单组件
```

### 核心 API
| API | 用途 | 兼容性 |
|-----|------|--------|
| Geolocation API | GPS 定位 | 95%+ 移动端 |
| DeviceOrientation API | 方向检测 | iOS 13+/Android |
| Permissions API | 权限预检 | 现代浏览器 |
| Canvas API | 指南针可视化 | 全兼容 |
| Web Worker | 计算异步化 | 性能优化 |

### 天文算法
- **NOAA Solar Calculator** - 日出日落时间（±1 分钟精度）
- **大气折射修正** - 地平线视差补偿 34'
- **逐分钟遍历** - 60Hz 精度扫描全天光照
- **遮挡投影模型** - 三角函数计算有效采光区域

## 📊 功能详情

### 1. 日照分析输出

点击"开始分析"后，系统生成以下数据：

| 指标 | 示例值 | 说明 |
|------|-------|------|
| 🧭 检测朝向 | 东南向 (135°) | 精确到度的方位角 |
| ☀️ 日照时长 | 6 小时 24 分钟 | 当日有效采光总时长 |
| 🌅 日出时间 | 06:23 | 当地真太阳时 |
| 🌇 日落时间 | 19:15 | 考虑大气折射 |
| 🕐 正午时间 | 12:49 | 太阳最高时刻 |
| 📈 光照评级 | ⭐⭐⭐⭐ 良好 | 综合评分（时长 + 朝向 + 类型） |

### 2. AI 智能助手

基于你的阳台数据，自动生成专业提示词，支持三个平台：

- 💙 **DeepSeek** - 深度思考型建议
- 🧡 **通义千问** - 阿里云大模型
- 🟣 **豆包** - 字节跳动轻量对话

**提示词内容包含**：
- 阳台朝向和经纬度
- 阳台类型和封闭情况
- 周边遮挡角度
- 今日日照时长和评级

**应用场景**：
- 🪴 植物种植建议（喜阴/喜阳品种推荐）
- 🛋️ 家具布局规划（避免阳光直射褪色）
- ☀️ 晾晒区最佳时段
- ⚡ 太阳能板发电效率估算
- 📸 摄影黄金光线捕捉

### 3. 全年日照详情

点击"📅 查看全年日照详情"查看每月变化趋势：

| 月份 | 平均日照 | 评级 |
|------|---------|------|
| 1 月 | 4h 28m | ⭐⭐⭐ 一般 |
| 7 月 | 8h 52m | ⭐⭐⭐⭐⭐ 极佳 |
| ... | ... | ... |

**季节性规律**：
- 夏季：日照长但角度偏高，需遮阳
- 冬季：日照短但角度低，易进室内
- 春秋：最舒适的光照强度

## ⚠️ 注意事项

### 精度说明
| 参数 | 精度 | 影响因素 |
|------|------|---------|
| 方向检测 | ±2° | 磁干扰、传感器校准 |
| GPS 定位 | 5-10m | 天空视野、多路径效应 |
| 日出日落 | ±1 分钟 | 海拔、大气折射 |
| 日照时长 | ±5 分钟 | 周边遮挡物估算 |

### 限制条件
- 需要 HTTPS 或 localhost 环境才能调用传感器 API
- iOS 设备需手动授权方向传感器权限
- 高楼密集区 GPS 信号可能不稳定
- 遮挡角度需用户自行测量（目测误差±10°）
